THIS FOLDER HOLDS YOUR BUTTON PICTURES
======================================
You don't need to do anything by hand. Open the app and use the SETUP page:
it takes the screenshots for you and saves them here.

Files the app creates in this folder:

  ready.png         the Ready / Play button in the lobby
  eliminated.png    the "ELIMINATED BY" text (you died, teammates still alive)
  menu.png          the menu button you click after pressing Esc
  leave.png         the Leave Match button
  return_lobby.png  the Return to Lobby button (your whole team is out)
  failsafe.png      optional: any popup you want clicked automatically

Want to make one yourself? Crop tightly (about 100-200 px wide), save as PNG
with the exact name above, and drop it in this folder.
